# Cammino Sonoro di Linz

Guida audio in italiano per il gruppo parrocchiale (Linz, fine marzo 2027).

- `mariendom/` — tappa pilota: pagina per il telefono (`index.html`), contenuti (`dati.js`), disegni (`disegni.js`) e libretto A5 da stampare (`libretto.html` → `libretto.pdf`).
- I contenuti stanno in `dati.js`: per cambiare un testo si modifica solo quel file.
- Nessun database, nessun tracciamento, nessun dato personale.
